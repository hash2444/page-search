# Page Search - Setup help

Everything you need to get **Page Search** running, step by step. If something goes wrong, check *Troubleshooting* at the end.

## What you need

- A Chromium browser: Chrome, Edge, Opera, Brave or Vivaldi

## Install and start

1. Download **`Page-Search.zip`** from the [Releases page](../../releases) - or directly from this repository.
2. Right-click the zip, **Extract All...**, and keep the extracted folder somewhere permanent (the browser loads the add-on from it).
3. Open `chrome://extensions` (Opera: `opera://extensions`, Edge: `edge://extensions`).
4. Switch on **Developer mode** (top right).
5. Click **Load unpacked** and choose the extracted folder.
6. Pin the add-on from the puzzle-piece menu so its icon stays visible.

## How to use it

- Click the magnifier icon, type a word: all matches light up, `Enter` jumps to the next one, `Shift+Enter` to the previous one.
- `Aa` switches case-sensitive matching on, *Whole word* only matches complete words.

## Troubleshooting

**The icon is missing**

Click the puzzle-piece icon in the toolbar and pin the add-on.

**It does nothing on some pages**

Browsers block add-ons on internal pages (`chrome://...`, the extension store, the new-tab page).

## Uninstall

Open `chrome://extensions`, click **Remove** on the add-on, then delete the extracted folder.
